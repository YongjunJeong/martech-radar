# Codex CLI 연동

앱은 `codex exec`를 별도 프로세스로 실행합니다. ChatGPT 계정 인증을 사용하므로 별도 LLM API 키를 등록하지 않아도 회사 조사와 문서 생성이 가능합니다. Codex 앱의 현재 대화나 토큰 잔액을 가져오는 구조는 아닙니다. 각각 독립된 작업이며 해당 계정의 Codex 사용량을 소비합니다.

## 설치와 계정

[공식 CLI 설치 안내](https://developers.openai.com/codex/cli)에 따라 설치한 뒤, 앱 또는 사설 gateway를 실행할 OS 계정에서 다음을 실행합니다.

```bash
codex --version
codex login
codex login status
```

`Logged in using ChatGPT`인지 확인합니다. CLI 인증을 다른 사용자의 웹 세션·쿠키로 대체하거나 인증 파일을 저장소·Docker 이미지에 넣지 않습니다. 서버에서의 로그인 방식은 [공식 인증 안내](https://learn.chatgpt.com/docs/auth)를 따릅니다.

검증한 CLI 버전은 **0.169.0**입니다. `--ignore-user-config`, `--ignore-rules`, `--ephemeral`, `--output-schema`, `--output-last-message`와 웹 검색 JSONL 이벤트를 사용합니다. 해당 옵션이 없는 버전은 실패하며 안전 옵션을 빼고 재시도하지 않습니다. CLI 업데이트 시 격리된 workspace에서 조사와 생성을 다시 검증하세요.

```toml
[preparation]
enabled = true
backend = "codex"
codex_binary = "/absolute/path/to/codex"
codex_model = ""
mkb_url = "http://127.0.0.1:8611"
timeout_seconds = 240
```

`codex_model`이 비어 있으면 CLI 기본 모델을 사용합니다. 개인 Codex 설정을 읽지 않으므로 개인 설정에 지정한 모델과 다를 수 있습니다. 이때 생성 기록은 `codex-default`로 남습니다. 기존 `model="sonnet"`은 Claude용이며 Codex에 전달하지 않습니다.

대시보드와 CLI의 실행 계정·PATH·인증 환경이 일치해야 합니다. 기존 운영 서비스에 적용하려면 작업이 없는 시간에 대시보드 또는 gateway를 재시작합니다. 수집 워커와 타이머는 AI 설정 변경 때문에 재시작할 필요가 없습니다.

## 실행과 근거 확인

- 임시 디렉터리에서 고정 지시문·JSON 스키마·표준 입력으로 실행합니다. 개인 설정·프로젝트 지침·스킬·MCP·앱·플러그인·셸·파일 변경 도구를 사용하지 않도록 설정합니다. read-only sandbox와 승인 요청 금지를 적용합니다.
- `forced_login_method="chatgpt"`를 지정하고 자식 프로세스에서 OpenAI API 키 환경변수를 제거합니다. 실패 시 API 방식으로 자동 전환하지 않습니다.
- **회사 조사:** 공개 기업명·업종·URL·날짜만 모델에 전달하고 웹 검색을 허용합니다. 검색 결과에 있거나 등록된 공개 URL이며 실제 열람 이벤트가 있는 자료만 후보로 받습니다. 별도 HTTP 조회로 발췌 문장이 본문에 있는지 확인합니다.
- 본문 재확인은 기존 공개 페이지 수집기의 robots·공개 주소·리디렉션·본문 크기 제한을 사용합니다. 최대 4개 자료를 공유 요청 예산(8회/30초) 안에서 확인하며, JavaScript 브라우저 재실행이나 차단 우회는 하지 않습니다. 읽을 수 없거나 발췌가 다르면 근거에서 제외합니다. 모델 요약 전체의 정확성을 증명하는 검사는 아닙니다.
- **추천·문서 생성:** 웹 검색을 끄고 검증된 KB·회사 자료와 사용자 제안 문맥으로 생성합니다. 모델 출력은 출처 ID·본문 인용·선택한 판매 솔루션·문서 구조 검증을 통과해야 저장합니다.
- 허용하지 않은 도구 이벤트, CLI 오류, 불완전한 응답, 시간 초과는 실패로 처리합니다. 프로세스 그룹을 종료하고 자동 재시도하지 않습니다. 기존 초안은 유지합니다.
- 회사 조사가 실패하거나 근거가 없으면 유사 업종 KB를 이용한 **가설**로 추천할 수 있습니다. KB 자체가 없거나 사용할 근거를 찾지 못하면 생성을 중단합니다.

추천 작업과 제안서·메일 생성은 별도 호출입니다. 검색과 생성이 이어지므로 전체 작업은 한 번의 호출 제한보다 오래 걸릴 수 있습니다. 상태는 종 아이콘에서 확인합니다. healthcheck는 실행 파일·KB 준비만 확인하며 모델을 호출하거나 인증 유효성을 확정하지 않습니다.

## 사용량과 배포 범위

모델은 OpenAI의 서비스에서 실행합니다. 입력 자료가 외부 모델에 전달되며, 사용 가능한 모델·사용량 한도·추가 크레딧은 계정의 요금제와 조직 정책에 따릅니다. “별도 API 키 불필요”는 “비용·한도 없음”을 뜻하지 않습니다. [공식 사용량 안내](https://learn.chatgpt.com/docs/pricing)

이 경로는 신뢰하는 운영자가 사용하는 앱과 인증된 사설 gateway를 위한 선택지입니다. 개인 계정을 불특정 다수에게 공유하는 공개 AI 서비스로 제공하는 조건을 보장하지 않습니다. 조직·외부 사용자에게 배포할 때는 계정 정책과 인증 구조를 별도로 검토해야 합니다. 별도 API 운영을 선택하려면 기존 [호스팅 API 구성](../deploy/PREPARATION_HOSTED.md)을 사용하며 별도 과금이 발생합니다.

## 문제 확인

| 증상 | 확인할 곳 |
| --- | --- |
| CLI 실행 실패 | 서비스 계정의 실행 경로, CLI 버전과 지원 옵션 |
| 인증·사용량 오류 | 같은 계정의 `codex login status`, Codex 사용량·조직 정책 |
| 회사 자료 부족 | 접근 가능한 공개 자료와 본문 발췌 검증 여부; 업종 가설 표시 확인 |
| KB 근거 부족 | `/search` 응답, 유사도·공개 출처·국내 채널 조건 |
| 출처·문서 검증 실패 | 이전 문서를 보존한 상태에서 입력 근거를 검토한 뒤 수동 재생성 |

로그에 인증 파일, 전체 프롬프트, 모델의 원문 오류를 출력하지 않습니다. 문제 신고에는 비공개 입력을 제거한 버전·설정 키 이름·오류 유형만 첨부하세요.
