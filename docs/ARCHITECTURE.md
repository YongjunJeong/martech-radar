# 구조와 데이터 흐름

```text
일정 / 수집 관리 → SQLite 작업 큐 → Chromium 워커 → 원본 근거 + 판정
                                             ↓
                             관측 이력 → 변화 요약 → 대시보드

제안 준비 버튼 → 공개 회사 조사 → Marketing KB 검색 → 유즈케이스 추천
                                                   ↓ 사용자 선택
                                              제안서 + 메일
```

## 저장

- `data/radar.db`: 기업·URL, 수집 계획·작업·관측·판정, 제안 초안·생성 상태의 기준 저장소입니다. SQLite WAL을 사용합니다.
- `data/`: 재판정용 원본 근거, 로그, 부하 표본과 운영 점검 결과입니다. 원본 수집 JSON을 없애면 fingerprint 수정 후 재판정이 제한됩니다.
- `targets.yaml`: 기업 목록 가져오기·내보내기입니다. DB와 동시에 편집해야 하는 별도 상태가 아닙니다.
- `radar.toml`: 수집·주기·분석 기간·접근 토큰·선택적 AI 설정입니다. `RADAR_HOME`으로 코드와 분리할 수 있습니다.
- `backups/`: SQLite online backup과 설정·fingerprint를 담은 검증된 복원 묶음입니다. 보관 수·용량 제한을 적용합니다. 외부 보관은 운영자가 설정합니다.

홈·상세 요약은 필요한 기간과 기업의 이력만 읽도록 제한하고 요청 안의 반복 계산을 공유합니다. 전용 검색 서버나 분산 큐를 필수로 두지 않습니다. 여러 프로세스가 같은 로컬 디스크의 DB를 사용하며 NFS·SMB 기반 DB 공유나 여러 호스트의 동시 writer는 지원하지 않습니다.

## 관측과 해석

브라우저가 실제 얻은 근거를 fingerprint 규칙으로 판정합니다. LLM은 솔루션 검출·변화 판정에 사용하지 않습니다. 정상 관측만 비교 대상으로 삼고 차단·불완전한 관측을 미검출로 바꾸지 않습니다. 최초 검출·다시 검출·반복 미검출도 실제 계약·사용 의도를 확정하지 않습니다.

약관의 솔루션 관련 문구는 별도 참고 테이블에 저장합니다. 브라우저 검출 상태나 연락 우선순위를 직접 바꾸지 않습니다. 자동 약관 수집은 HTTP만 사용하고 주 수집·생성 작업과 자원 사용량을 확인해 연기할 수 있습니다.

## AI 경계

AI 기능은 기본 비활성화입니다. 수집 워커는 KB나 LLM을 호출하지 않습니다. 웹 프로세스의 생성 작업은 DB별 잠금으로 제한되며, 사설 gateway를 사용하면 gateway에도 별도 실행 잠금이 적용됩니다.

- `cli`: 기존 Claude CLI 경로.
- `codex`: ChatGPT 인증 Codex CLI. 회사 조사 때만 웹 검색을 허용합니다.
- `anthropic`: 명시적으로 선택한 API 경로. 별도 키·과금이 필요합니다.
- `gateway_url`: 설정하면 KB 검색·조사·생성을 인증된 사설 gateway에 위임합니다. 실제 백엔드는 gateway 설정이 결정합니다.

회사 공개 자료와 KB 사례는 출처를 구분합니다. 회사 자료가 부족하면 업종 가설로 표시하고 KB가 없으면 추천을 저장하지 않습니다. 생성은 자동 재시도하지 않으며, 제안서와 메일은 둘 다 검증됐을 때 함께 저장합니다. 재시작으로 중단된 작업은 실패로 표시하고 이전 결과를 보존합니다.

## 작업 복구의 현재 경계

워커는 스캔 결과·탐지 결과·완료 상태를 하나의 SQLite 트랜잭션으로 확정합니다. 만료된 claim은 다음 claim 시 pending으로 되돌아갑니다. 현재 `finish_job()`과 `fail_job()`은 job ID로 상태를 갱신하며 실행별 소유권 토큰을 확인하지 않습니다. 따라서 기존 워커가 claim 만료 후 다시 실행되면 재할당된 작업에 늦게 결과를 쓸 가능성이 있습니다. 다중 워커 복구를 검증할 때는 A의 claim 만료, B의 재할당·완료, A의 늦은 완료 순서를 재현하고 결과 확정 권한을 확인해야 합니다.
