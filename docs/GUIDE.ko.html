MarTech Radar 사용 안내

공개 웹사이트의 마케팅 솔루션 관측과 변화 근거를 확인하고, 회사 조사·유즈케이스 추천·제안서·메일 초안으로 이어갑니다. 데스크톱 웹을 기준으로 사용합니다.

설치와 운영 안내는 아래 문서에서 관리합니다. 저장소의 Markdown 문서는 GitHub에서 보거나 Markdown 뷰어로 열 수 있습니다.

  • README — 설치, 기업 등록, 수집과 대시보드 실행
  • 제안 준비 — 회사 조사, 시나리오 선택, 제안서와 메일 생성
  • Codex 연동 — ChatGPT 계정 로그인, 별도 LLM API 키 없이 실행하는 방법과 사용량
  • Marketing KB — 별도로 준비할 검색 서비스와 응답 계약
  • Ubuntu 운영 — 예약 수집, 약관 참고, 누락·부하 점검과 백업
  • 컨테이너·호스팅 — 격리 검증과 전환 절차

관측을 읽는 방법

기업 상세에서 전체 요약을 확인한 뒤 솔루션별 이전·최근 관측일과 검출 근거를 펼칩니다. 최초 검출은 신규 도입, 미검출은 사용 중단을 확정하지 않습니다. 차단·불완전한 수집은 판단 불가로 구분하며, 약관 문구도 별도 참고 정보입니다.

데이터 보관

실행 중인 DB 파일을 단독 복사하지 말고 radar backup을 사용합니다. 실제 기업 목록, 설정·접근 토큰, CLI 인증과 생성 문서는 비공개로 관리합니다.
